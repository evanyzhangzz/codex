# ULVZ 波速与密度异常对比页预览

这是针对用户新修改意见制作的单页预览，不是已完成的全套新版PPT。

以周围正常地幔为零异常：Vp −8%、Vs −24%、密度约 +10%；对应正常地幔=100%时分别为92%、76%、约110%。

数值取自Dannberg et al. (2021), GJI, p.1048（PDF第21页）对Rost et al. (2005, 2006)同一区域ScP反演模型的汇总。该图是代数归一化/重新绘图，没有重新反演波形，也没有添加文献未提供的误差条。密度由振幅约束，其不确定性较高。

完整空间关系页计划使用外部综述中同时含CMB、LLSVPs、ULVZ的原图。当前期刊访问被云环境网络规则拦截，已保存所需域名草稿，待环境设置审核保存并发布后继续。

已知前提：MLD低速观测、CaCO3的物质存在依据、高温结构信息与弹性/全岩效应之间仍需量化的环节。

总问题：**MLD温压条件下，固态CaCO3是否具备解释部分低速异常的物性条件？**

两层检验：
1. 端元物性：弹性与波速处于什么水平，如何随温压变化？
2. 全岩效应：少量混入橄榄岩后，是否产生观测量级的Vs降低？

不预设一定存在新相、压力相变、剪切软化或足够低速。结构变化与具体机制应由结果确定。两个层次分别可以得到肯定或否定的答案，即使端元低速，少量混合也可能不足以产生观测幅度。

“端元物性→矿物对比→全岩效应”明确标为检验路径，而非三条已经知道答案的问题。讲述备注说明全岩降幅的基准为同温压下不含CaCO3的橄榄岩。

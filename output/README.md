## 下载

1. 登录有权访问此仓库的 GitHub 账号。
2. 打开同目录的 `CMB_ULVZ_24slides.pptx`。
3. 点击文件页面上的 **Download raw file**（下载图标）。GitHub 无法在线预览 PPTX 时，仍可使用该按钮下载。
4. 也可在本分支页面选择 **Code → Download ZIP**，解压后从 `output` 目录取得 PPTX。
